🛠️ Deck Builder — suggestions par affinité

Suggestions calculées à partir des decks connus localement (onglet "Base de decks") : quelles cartes reviennent le plus souvent dans les decks qui jouent le leader et/ou les cartes déjà choisies ci-dessous. Pas d'analyse du texte des cartes — uniquement ce que les decks réellement importés jouent ensemble. Plus la base locale est grande, plus les suggestions sont pertinentes : pense à lancer "Importer / mettre à jour" dans l'onglet Base de decks si tu n'as pas encore de données.

Ouvrir swudb.com "My Decks" ↗
swudb.com (page "My Decks") a un bouton ".json" qui construit un deck à partir du contenu de ton presse-papier. Ce bouton génère ce JSON pour toi (format confirmé à partir d'un vrai export swudb) — clique-le, ouvre swudb via le lien ci-dessus, clique ".json".
