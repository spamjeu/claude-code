🔎 SWU Card & Text Finder

Recherche de cartes Star Wars: Unlimited par texte / mot-clé plutôt que par leader — pensé pour repérer les cartes liées au mécanisme Advantage (jeton d'avantage temporaire, +1/+0) introduit dans Ashes of the Empire (ASH). Données : API publique api.swu-db.com.
Syntaxe libre supportée (transmise telle quelle à l'API si tu préfixes ta recherche par raw:) : t: texte, ty: type, a: aspect, ar: arena, r: rareté, set: set, c=/p=/h= coût/power/HP, AND/OR, parenthèses. Doc complète : swu-db.com/syntax.
🗂️ Base de decks locale (Premier)

Indexe localement des decks publiés sur SWUDB (format Premier) pour retrouver ceux qui jouent une carte donnée. L'import tourne depuis server.js et le résultat est stocké dans data/decks.json sur ta machine — rien n'est envoyé à un tiers.

Source des données : API interne (non documentée) de swudb.com. Voir aussi SWU Meta Stats pour les stats de méta globales.
Outil non officiel, données via l'API publique swu-db.com. Requêtes relayées par le petit proxy local server.js (aucune donnée envoyée à un tiers).
